Privacy Policy - DRS Bill

Last updated: August 26, 2026

About DRS Bill

DRS Bill is an offline billing application designed to help businesses manage products, bills, parties, payments, and related business records.

Data Storage

DRS Bill primarily stores application data locally on the user's device. This includes information such as products, bills, parties, payments, and business settings.

Google Account

DRS Bill uses Google Sign-In to allow the user to authenticate their Google account when using the optional backup and restore functionality.

Google account authentication is only used when the user chooses to use Google Drive backup or restore.

Google Drive Backup

DRS Bill provides an optional backup feature that allows the user to store a backup of the application's local database in the application's private Google Drive storage.

The backup contains the application's local database and may therefore contain the business information stored by the user within DRS Bill.

The application does not upload the database to Google Drive automatically. The user must explicitly choose the backup functionality.

Google Drive Restore

DRS Bill also provides an optional restore feature. When the user chooses to restore a backup, the application downloads the previously created database backup from the user's Google Drive application storage and replaces the local application database with that backup.

Data Sharing

DRS Bill does not sell or share the user's application data with third parties for advertising or marketing purposes.

When the user chooses Google Drive backup, the backup is stored using the user's Google Drive account and is subject to Google's applicable policies.

Data Security

The application is designed to keep normal application data stored locally on the user's device. Google Drive backup is performed only when explicitly requested by the user.

Data Deletion

The user can remove locally stored application data by deleting the application or using the application's available data management options.

Google Drive backups can be removed through the application's backup functionality or through the user's Google account and associated application data.

Changes to This Privacy Policy

This Privacy Policy may be updated from time to time. Any changes will be published on this page with an updated revision date.

Contact

If you have questions about this Privacy Policy or DRS Bill, please contact the application developer.
