Privacy Policy

Last updated: August 26, 2026

DRS Bill

DRS Bill is a billing application designed for internal use.

Data Storage

The application stores billing and business data locally on the user's device.

Google Drive Backup

If the user chooses to use the backup feature, the application uses Google Drive to store a backup of the application's local database.

Google Drive access is used only when the user chooses the backup or restore functionality.

Google Account

The application uses Google authentication to access the user's Google Drive application data for backup and restore purposes.

Contact

For questions about this application, please contact the application developer.
